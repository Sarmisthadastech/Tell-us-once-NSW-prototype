# Tell us once (prototype)

A prototype of a "tell us once" citizen-services flow for NSW life events. A person reports an event once, chooses which agencies to notify, and sees simulated progress.

**This is a prototype, not an official NSW Government service.** It uses made-up data, does not connect to any agency and sends nothing anywhere. Please do not enter real personal details.

## Run it

Open `index.html` in a browser. There is no build step and no dependencies.

## Files

- `index.html` is the whole app (HTML, CSS and JavaScript in one file).
